# Past projects

Projects this user built before are in your file system under `/references/` (every file is listed
below). When the request is like one of them (same kind of robot or device, drive, actuators,
sensors or boards), read the closest one with `read_file` before you decide, starting at its
pack's `README.md`, and reuse what fits your own section: part choices, power design, pin map, CAD
notes, firmware structure and lessons learned. Skip them when nothing is similar.
- They are notes, not the part library: their part ids aren't library ids. Map each part to a
  library part (`search_parts`) or a custom part as above. Where they disagree with these rules,
  these rules win.
- When you followed one, name it in your reply.
