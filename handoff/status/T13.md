deepagents version: 0.7.38 (langchain 1.5.0, langgraph 1.2.22). API used:
- `create_deep_agent(model, tools, *, system_prompt, middleware, subagents, memory, interrupt_on, checkpointer)`
- Sub-agents: dicts with `name`, `description`, `system_prompt`, `tools`, `model` (one model per sub-agent).
- Planning is opt-in: `middleware=[TodoListMiddleware()]` (`langchain.agents.middleware`); todos come from
  `state["todos"]` through `astream(..., stream_mode="values")`.
- general-purpose turned off with `register_harness_profile(<model spec>, HarnessProfile(general_purpose_subagent=GeneralPurposeSubagentProfile(enabled=False)))`,
  keyed on our exact model string (models passed as instances, like the fakes in tests, keep it).
- Questions: `interrupt_on={"ask_user": {"allowed_decisions": ["respond"]}}`; pending from
  `(await agent.aget_state(cfg)).interrupts`; resume with `Command(resume={"decisions": [{"type": "respond", "message": ...}]})`.
- Threads: `InMemorySaver()` with `thread_id = run_id`.
- Memory: `memory=["/AGENTS.md"]` in the default `StateBackend`, given as input `files={"/AGENTS.md": create_file_data(text)}`.
- Parallel firmware + enclosure: two `task` calls in one message (ToolNode runs them at the same time).
  Async sub-agents need a LangGraph server, so we don't use them.
- `P2D_MODEL`: `provider:model` or a bare name (gets `anthropic:` in front).
