Decisions for the G0 review (changes from the card, all in the code and CLAUDE.md):
1. Every tool that makes files takes an `out_dir`: `compute_layout(spec, lib, out_dir)` and
   `price_bom(spec, lib, prices, owned, out_dir)` gained one. New tool `build_wiring` (T14's
   backend/runtime/wiring.py) so the agent and the edit flow call wiring through the ToolBox.
2. `Runner` is async (`run`, `edit`, plus `answer` for question replies); `emit` is a plain,
   thread-safe callable, and the engine sets `seq`/`ts`. Run dirs come from `run_dir_for(run_id)`
   ($P2D_RUNS_DIR).
3. "Didn't run" is signalled by error codes `not_implemented`/`skipped` (`ToolResult.skipped`).
4. Geometry conventions in base.py; `Placement` adds `z_mm`, and `rot_deg` is 0/90/180/270.
5. Parts: pin types are MCU-side directions; added `config` pin type, `optional` pins,
   `mounting: external` (soil probe: cable hole, no placement), `adc1_pins`, `power_budget_ma`,
   `wokwi_pins`/`wokwi_attrs`.
6. Shared run files have models in artifacts.py (Bom, Wiring, RunManifest, EnclosureManifest).
